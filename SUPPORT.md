# Support

| Question | Where |
|---|---|
| Penelope does something wrong | an issue with the form "Bug report" in [Penelope](https://github.com/LaertesAI/Penelope/issues/new/choose) |
| An idea for a tool, a command or a setting | an issue with the form "Idea" |
| A weakness that leaks a secret or skips a question | in private, see [SECURITY.md](SECURITY.md) |
| Which providers and addresses Penelope knows | `penelope providers`, or `docs/PROVIDERS.md` in the repository |
| What is planned and what is a known limit | `docs/ROADMAP.md` in the repository |

Before an issue, run `penelope doctor` and read its lines that start with `FAIL`.

No paid support and no fixed answer time exist. One developer reads the issues.
