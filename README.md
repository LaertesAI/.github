# .github

The profile and the default files of the organisation [LaertesAI](https://github.com/LaertesAI).

| Path | What GitHub does with it |
|---|---|
| [`profile/README.md`](profile/README.md) | shows it on the page of the organisation |
| [`profile/lockups/`](profile/lockups) | the ten lockups (picture, name and job) at 688 pixels on the paper colour, used by the profile |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | links it when someone opens an issue or a pull request |
| [`SECURITY.md`](SECURITY.md) | shows it under Security of a repository |
| [`SUPPORT.md`](SUPPORT.md) | links it on the page for a new issue |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | links it in the community profile |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) | offers the forms "Bug report" and "Idea" |
| [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | fills the text of a new pull request |

A default file counts for a public repository that has no file of the same kind. A repository with any file in its
own `.github/ISSUE_TEMPLATE` folder uses none of the forms here.

The version and the state in `profile/README.md` are written by hand. Change them with every release of Penelope.
