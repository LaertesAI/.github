# Code of conduct

This file holds for every issue, pull request and comment in the repositories of Laertes.

## Expected

- Write about the code, the run and the number. Leave the person out of it.
- Name what you measured and how. Say so when you did not measure.
- Accept a "no" to a proposal. One developer decides what the project takes.
- Answer in English, so every reader can follow.

## Not accepted

- Insults, threats and remarks about origin, gender, age, religion, body or health.
- Private data of another person in an issue, a comment or a log.
- Advertising and repeated posts on the same point.

## What happens

A maintainer hides or removes such a post. A second case leads to a block from the organisation.

## Report

Use the report entry in the menu of the post on GitHub.
